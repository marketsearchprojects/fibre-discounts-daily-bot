# Privacy policy

Last updated: 9 August 2026

Fibre Global Insight is a Devvit app used in `r/FibreDiscounts`. It creates educational posts and does not collect or sell personal data.

The app does not send Reddit posts, comments, usernames, email addresses or other Reddit user content to OpenAI. Its external request contains only the current publication date, editorial instructions and previously used public source URLs. OpenAI is used to search public web sources and draft structured editorial content.

Within the subreddit installation's Devvit Redis storage, the app keeps publication dates, its own generated Reddit post IDs and up to 90 previously used public source URLs. This data exists only to prevent duplicate posts and repeated sources. The OpenAI API key is stored as a Devvit global secret and is never included in posts or logs.

Uninstalling the app ends its operation in the community. Questions or deletion requests can be sent by modmail to `r/FibreDiscounts`.

OpenAI processes API requests under its own applicable privacy and API data policies. Reddit processes Devvit and Reddit account data under Reddit's policies.
